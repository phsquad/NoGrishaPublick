✨ Почему "Не Гриша"?

Надоело каждую неделю спорить, чья очередь дежурить? Устали от обид и чувства несправедливости? Этот бот был создан, чтобы решить эти проблемы раз и навсегда. Он вносит в процесс:

    Справедливость: Умный алгоритм повышает шансы тех, кто давно не дежурил или имеет "долги".

    Прозрачность: Каждый участник может посмотреть свою статистику и понять, почему выбор пал именно на него.

    Вовлеченность: Система званий, рейтинги и серии превращают обязанность в соревнование.

    Автоматизацию: Больше никаких списков на бумажке. Бот всё делает сам, включая напоминания дежурным.

🚀 Ключевые возможности

Этот бот — настоящий швейцарский нож для управления командными задачами:

    🧠 Умный и справедливый розыгрыш: Шанс быть выбранным динамически меняется! Вес каждого участника зависит от:

        Долга по дежурству: Пропустил свою очередь? Твой шанс в следующий раз выше!

        Серии пропусков: Давно не был дежурным? Рулетка заметит это!

    🛡️ Система "Отдыха" (Cooldown): Только что отдежурил? Бот даст тебе отдохнуть и не выберет в следующих нескольких розыгрышах.

    🏆 Лиги "Новичков" и "Ветеранов": Бот старается чаще выбирать тех, у кого мало дежурств, чтобы все участвовали наравне.

    🆘 Режим "SOS" для поиска замены: Дежурный не может выйти? Админ запускает клич, и первый откликнувшийся герой получает иммунитет на свой следующий ход!

    👑 Графический рейтинг и звания: Команда /stats генерирует красивую картинку с рейтингом всех участников, от "Новобранца чистоты" до "ВЕРХОВНОГО МАГИСТРА ШВАБРЫ".

    ⚙️ Интерактивная админ-панель: Удобное меню с кнопками для управления пользователями, сброса циклов, создания объявлений и диагностики бота.

    📊 Личный профиль и прозрачность: Каждый может посмотреть свою статистику, долги, иммунитет и текущий "вес" в рулетке командой /profile.

    🔔 Личные уведомления: Победители розыгрыша получают вежливое напоминание в личные сообщения со своей задачей.

    💾 Надёжное хранение данных: Вся история, статистика и настройки хранятся в облачной базе данных PostgreSQL, поэтому ничего не потеряется.

🔧 Установка и запуск

Хотите запустить свою версию бота? Это просто!

    Клонируйте репозиторий:
    code Bash

    
git clone https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ

  

Установите зависимости:
code Bash

    
pip install -r requirements.txt

  

(Не забудьте создать requirements.txt файл: pip freeze > requirements.txt)

Настройте переменные окружения:
Создайте файл .env или настройте переменные на вашем хостинге:
code Env

    
# Токен вашего бота от @BotFather
TOKEN="12345:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"

# URL вашего вебхука (например, от Render)
WEBHOOK_URL="https://your-app-name.onrender.com"

# Строка подключения к вашей базе данных PostgreSQL
DATABASE_URL="postgresql://user:password@host:port/database"

# ID группового чата, где работает бот
GROUP_CHAT_ID="-100123456789"

# Список администраторов через запятую (по юзернеймам)
ADMIN_USERNAMES_LIST="admin1,admin2"

# Список администраторов через запятую (по ID)
ADMIN_IDS_LIST="12345678,87654321"

  

Запустите бота:
Бот использует Flask для вебхуков, поэтому рекомендуется запускать его через Gunicorn:
code Bash

        
    gunicorn duty_bot:app
